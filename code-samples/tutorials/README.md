# Samples from the Adobe Express Embed SDK Tutorials

This folder contains samples written by the Developer Experience team at Adobe, as part of the [Embed SDK Tutorials](https://developer.adobe.com/express/embed-sdk/docs/guides/tutorials/).

> [!WARNING]
> This repository is a work-in-progress: the samples are being added and updated regularly—please check back often, and excuse any temporary inconsistencies.

## List of Samples

- [`embed-sdk-getting-started`](./embed-sdk-getting-started/README.md): code sample for the [Getting Started](https://developer.adobe.com/express/embed-sdk/docs/guides/tutorials/getting-started) tutorial—a quicker, gentler introduction to the Embed SDK.
- [`embed-sdk-full-editor`](./embed-sdk-full-editor/README.md): code sample for the [Full Editor](https://developer.adobe.com/express/embed-sdk/docs/guides/tutorials/full-editor) tutorial—implementing a full-featured Adobe Express editor that can create and edit documents, as well as managing them in your web application.
- [`embed-sdk-edit-image`](./embed-sdk-edit-image/README.md): code sample for the [Edit Image](https://developer.adobe.com/express/embed-sdk/docs/guides/tutorials/edit-image) tutorial—using the Edit Image module to edit images.
- [`embed-sdk-generate-image`](./embed-sdk-generate-image/README.md): code sample for the [Generate Image](https://developer.adobe.com/express/embed-sdk/docs/guides/tutorials/generate-image) tutorial—using the Generate Image module to generate images from text.
- [`embed-sdk-workflow-tethering`](./embed-sdk-workflow-tethering/README.md): code sample for the [Workflow Tethering](https://developer.adobe.com/express/embed-sdk/docs/guides/tutorials/workflow-tethering) tutorial—linking multiple workflows together to create a seamless experience.
- [`embed-sdk-mobile-web`](./embed-sdk-mobile-web/README.md): code sample for the [Mobile Web](https://developer.adobe.com/express/embed-sdk/docs/guides/tutorials/mobile-web) tutorial—creating Android/iOS applications that consume Mobile Web experiences via WebView.
